01

사용자는 어떻게 움직일까?

USER JOURNEY

페이지를 보여주는 것에서 끝나지 않고, 한 번의 학습 흐름이 끝날 때까지 사용자가 무엇을 하는지 따라가 본다.

STEP 01

홈페이지에서 STUDY를 누른다.

사용자가 homepage-test.html에 접속해 상단 메뉴에서 Study를 선택하고 study.html로 이동한다.

STEP 02

공부할 조건을 골라본다.

테이블(6-Max/9-Max) → 상황(RFI/Facing Open/3-Bet/4-Bet) → 포지션 → 상대 포지션 → 유효 스택 순으로 선택한다. 169개 핸드 중 하나를 클릭하거나 검색한다.

STEP 03

선택한 핸드의 정보를 확인한다.

오른쪽 패널에 선택한 조건, 핸드 이름과 카드 조합이 나타난다. 실제 Raise/Call/Fold 전략 빈도는 아직 데이터가 없으므로 '데이터 준비 중'으로 표시된다.

STEP 04

Practice에서 실제로 선택해 본다.

Practice로 이동하면 랜덤 핸드가 자동으로 나온다. 포지션과 스택 등 상황을 보고 Fold, Call, Raise 중 하나를 고른다.

STEP 05

다음 핸드로 넘어간다.

행동을 선택하면 Next Hand 버튼이 활성화된다. 버튼을 누르면 직전 행동이 기록되고 새로운 랜덤 핸드가 나온다.

STEP 06

내가 어떻게 연습했는지 돌아본다.

Practice의 Session과 History 패널에서 연습 횟수와 행동 기록을 확인한다. 새로고침해도 기록은 현재 브라우저의 localStorage에 유지된다.

현재의 한계: 아직 별도의 Analyze 전용 화면은 없다. 연습 기록을 실제로 확인할 수 있는 곳은 Practice 화면의 Session / History이며, 로그인이나 클라우드 동기화도 제공되지 않는다.

01 / FEATURE SPEC

프리플랍 핸드 레인지 탐색기

현재 구현 · 전략 데이터 미연결

01
01 / 무엇을 하나요?

테이블(6-Max/9-Max), 상황(RFI/Facing Open/3-Bet/4-Bet), 포지션, 상대 포지션, 유효 스택 버튼 클릭 / 169칸 그리드에서 핸드 클릭 / 검색창에 핸드 표기 입력(예: AKs) / "선택 초기화" 버튼 클릭

02 / 화면에서는 무슨 일이?

테이블·상황 변경 시 포지션·상대 포지션 버튼 목록이 다시 그려짐. 핸드 클릭/검색 성공 시 그리드에 선택 하이라이트, 오른쪽 패널에 핸드명·조합 수·실제 카드 조합 칩이 표시됨

03 / 예외 상황은?

RFI 상황에는 상대 포지션 버튼 자체가 없고 안내 문구 표시. 포지션 선택 전엔 "먼저 포지션을 선택해주세요" 안내. 행동 순서상 불가능한 상대 포지션은 버튼이 비활성화(클릭 불가). 검색창에 유효하지 않은 랭크 문자를 입력하면 "올바른 핸드 표기를 입력해주세요" 에러 메시지. 전략 수치는 항상 "데이터 준비 중" 고정 표시

04 / 지금 어디까지?

✅ 구현됨 (UI·조작 전부 동작). "선택 초기화"는 핸드/포지션/상대 포지션/검색어만 초기화하며 테이블·상황·스택은 초기화하지 않음(코드 기준 확인된 동작)

필수 기능
02 / FEATURE SPEC

랜덤 핸드 의사결정 연습

현재 구현 · 정답 판정 없음

02
01 / 무엇을 하나요?

Fold / Call / Raise 버튼 중 하나 클릭 → Next Hand 버튼 클릭 / "기록 전체 초기화" 버튼 클릭

02 / 화면에서는 무슨 일이?

행동 선택 시 해당 버튼이 활성 표시되고 Next Hand가 눌릴 수 있게 됨. Next Hand 클릭 시 방금 행동이 기록되고, 연습한 핸드 수·기록된 행동 수가 올라가며, HISTORY 리스트 맨 위에 새 기록이 추가되고, 테이블에 새 랜덤 핸드가 딜링됨

03 / 예외 상황은?

행동을 아직 선택하지 않았다면 Next Hand 버튼이 비활성화되어 애초에 누를 수 없음(에러 메시지 대신 버튼 자체를 막는 방식). 기록이 하나도 없을 때 HISTORY 영역에는 "아직 기록된 연습 기록이 없습니다" 안내 표시. localStorage 저장이 실패하는 경우(예: 브라우저 저장소 차단) 코드상 오류를 조용히 무시하도록 되어 있어 사용자에게 별도 에러 안내는 뜨지 않음 — 향후 보완이 필요한 지점

04 / 지금 어디까지?

✅ 구현됨. 정답/오답 판정이나 정확도는 전혀 표시하지 않으며 선택한 행동만 기록함(의도된 동작)
